# RAG系统评估程序说明

## 程序概述

本评估程序基于RAGAS库，用于评估RAG（检索增强生成）系统的性能。程序通过执行完整的RAG查询流程，计算5个关键指标来评估系统质量。

## 文件说明

- `eval.py` - 评估主程序
- `qa.csv` - 测试数据集（需自行准备）
- `qa_example.csv` - 测试数据集示例
- `qa_result.csv` - 评估结果输出

## 测试数据格式要求

`qa.csv` 文件必须包含以下两列：

| 列名 | 说明 | 示例 |
|------|------|------|
| question | 测试问题 | "H3C LA2608如何使用？" |
| ground_truth | 标准答案（参考答案） | "H3C LA2608是一款企业级无线接入点..." |

### 示例数据

```csv
question,ground_truth
"H3C LA2608如何使用？","H3C LA2608是一款企业级无线接入点，通过浏览器访问其管理界面进行配置..."
"主板短路如何检测？","主板短路检测方法：1.使用万用表蜂鸣档测量主供电电感的对地阻值..."
```

## 使用方法

### 1. 准备测试数据

将测试数据保存为 `eval/qa.csv`，确保文件编码为UTF-8 with BOM。

### 2. 运行评估程序

```bash
cd D:\AIpractise\shopkeer_brain
python eval/eval.py
```

### 3. 查看评估结果

评估结果将保存在 `eval/qa_result.csv`，包含以下9列：

1. **question** - 测试问题
2. **context** - RAG检索到的上下文内容
3. **answer** - RAG生成的答案
4. **ground_truth** - 标准答案
5. **faithfulness** - 忠实度（答案是否基于检索到的上下文）
6. **answer_relevancy** - 答案相关性（答案与问题的相关程度）
7. **context_precision** - 上下文精确度（检索到的文档是否相关）
8. **context_recall** - 上下文召回率（是否检索到了所有相关文档）
9. **answer_correctness** - 答案正确性（答案与标准答案的一致性）

## 评估指标说明

### 1. Faithfulness（忠实度）
- **定义**: 生成的答案是否基于检索到的上下文，是否存在幻觉
- **取值范围**: 0-1，越高越好
- **评估方式**: LLM判断答案中的每个主张是否能在上下文中找到依据

### 2. Answer Relevancy（答案相关性）
- **定义**: 生成的答案是否与问题相关
- **取值范围**: 0-1，越高越好
- **评估方式**: 基于答案生成反向问题，与原问题比较相似度

### 3. Context Precision（上下文精确度）
- **定义**: 检索到的文档是否与问题相关
- **取值范围**: 0-1，越高越好
- **评估方式**: 判断检索到的文档是否包含标准答案的依据

### 4. Context Recall（上下文召回率）
- **定义**: 是否检索到了所有相关文档
- **取值范围**: 0-1，越高越好
- **评估方式**: 判断标准答案的依据是否在检索到的文档中

### 5. Answer Correctness（答案正确性）
- **定义**: 生成的答案与标准答案的一致性
- **取值范围**: 0-1，越高越好
- **评估方式**: 比较生成答案与标准答案的语义相似度和事实一致性

## 程序流程

```
【步骤1】读取测试数据集
    ↓
【步骤2】初始化RAGAS评估模型
    ↓
【步骤3-4】执行RAG查询（获取答案和上下文）
    ↓
【步骤5】准备RAGAS评估数据集
    ↓
【步骤6】执行RAGAS指标评估
    ↓
【步骤7】保存评估结果
```

## RAG流程说明

程序使用以下RAG流程：

1. **入口**: `knowledge/processor/query_process/main_graph.py` 中的 `query_app.invoke`
2. **上下文提取**: 从 `state.reranked_docs` 提取排序后的文档作为上下文
3. **LLM模型**: 通过 `knowledge/utils/llm_client_util.py` 获取
4. **Embedding模型**: 通过 `knowledge/utils/bgem3_client_util.py` 获取

## 注意事项

1. **环境变量**: 确保 `.env` 文件中配置了正确的API密钥和模型路径
2. **模型依赖**: 需要安装 `ragas`、`datasets` 等依赖包
3. **编码格式**: 输入和输出文件均使用 UTF-8 with BOM 编码
4. **评估时间**: 根据测试数据量，评估可能需要较长时间（涉及多个LLM调用）

## 故障排除

### 问题1: 找不到qa.csv文件
**解决**: 确保 `eval/qa.csv` 文件存在，并包含至少一行数据（不含表头）

### 问题2: LLM调用超时
**解决**: 检查网络连接，确保 `.env` 中的API地址和密钥正确

### 问题3: 模型加载失败
**解决**: 确保 `.env` 中 `BGE_M3_PATH` 指向正确的模型路径
