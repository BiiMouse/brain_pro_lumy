🔧 技术栈

  - LangGraph: 工作流编排
  - OpenAI: LLM 和视觉模型
  - Milvus: 向量数据库（语义检索）
  - Neo4j: 图数据库（知识图谱）
  - MinIO: 对象存储（图片等文件）
  - MinerU: PDF 解析和转换
  - Sentence Transformers: 文本向量化

  🎯 设计亮点

  1. 基于工作流的节点设计：每个处理步骤都是独立的节点，易于扩展和测试
  2. 强类型状态管理：使用 TypedDict 避免数据传递错误
  3. 分层异常体系：清晰的错误分类和处理
  4. 配置与代码分离：使用环境变量管理敏感信息和配置
  5. 多模态支持：同时处理文本和图片，存储到不同的数据库

  这是一个典型的 RAG（检索增强生成）知识库构建系统，支持从文档导入到向量化存储的全流程。
